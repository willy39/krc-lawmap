# 판례·해석 검수 가이드 (담당자용)

주간 수집 PR 본문의 **검수 대기(candidate)** 목록을 확인하고 `data/review.yaml` 에 결과를 기록해 같은 PR(또는 별도 PR)로 반영한다. 목표: 대기열 2주 이내 처리.

1. **승인(approved)**: 대한적십자사가 당사자·질의기관이거나, 조직법·정관·기관규정의 해석이 쟁점이거나, 혈액·헌혈·구호 사업 수행과 직접 관련된 판단.
2. **제외(rejected)**: 기관명이 사실관계에 지나가듯 등장할 뿐 쟁점과 무관(예: 경력 기재, 기부처 언급). 제외 항목은 재수집 시에도 노출되지 않는다.
3. **쟁점태그**: 2~4어절 명사구로 통일(예: `헌혈자 개인정보`, `적십자회비 법적 성격`, `혈액원 근로자 해고`). 신규 태그는 `data/taxonomy.yaml` 의 `issueTags` 에 등록.
4. **연결 규범 지정**: 참조조문 자동 연결이 없거나 틀렸으면 `about` 에 `normId#제n조` 형식으로 지정.

```yaml
"prec:123456":
  review: approved
  issueTags: [헌혈자 개인정보]
  about: ["law:혈액관리법#제12조"]
"expc:654321":
  review: rejected
  note: 기관명만 언급, 쟁점 무관
```

점수 가중치·임계값은 `data/relevance.yaml` 에서 조정한다.
